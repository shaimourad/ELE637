This repository contains coursework and simulations related to signal processing and system analysis completed in ELE637. The course introduced continuous and discrete-time signals, linear systems, transforms, and frequency-domain analysis.

Topics explored include:

Fourier series and Fourier transforms

Laplace transforms

Z-transforms

Convolution and system response

Sampling theory

Filter analysis and design

MATLAB and simulation tools were used extensively to model and analyze engineering systems and signal behavior.
